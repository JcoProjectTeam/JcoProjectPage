# MIN Function

Returns the minimum of two values.

## Syntax
    MIN(x, y)

## Semantics
- `x`, `y`: Numeric inputs (INT or FLOAT)
- Returns the smaller of `x` and `y`.

## Example
```jcoql
EVALUATE minVal AS MIN(3, 7)   // minVal = 3
```
