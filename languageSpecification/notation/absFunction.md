# ABS Function

Returns the absolute value of a number.

## Syntax
    ABS(x)

## Semantics
- `x`: Numeric input (INT or FLOAT)
- Returns the non-negative value of `x`.

## Example
```jcoql
EVALUATE result AS ABS(-5)   // result = 5
```
