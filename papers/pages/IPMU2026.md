# On Veracity Handling in Document Stores: A Novel Technique Based on L-graded Logic Running on the J-CO Framework

### Abstract
Data veracity denotes the trustworthiness and reliability of
information and remains a primary challenge in managing big data. Man-
aging data veracity in NoSQL database systems (such as JSON -based
document stores) remains an open challenge, whereas computational in-
telligence techniques like fuzzy logic offer promising tools for addressing
it. Specifically, a fuzzy logic framework using a specific kind of truth val-
ues, called L-grades, has been designed to assess trust in flexible query
answering. In an independent work, the J-CO Framework has been de-
veloped to provide flexible query answering on top of NoSQL document
stores. The present work studies the integration of both frameworks: it
proposes a novel technique, based on L-grade logic and demonstrates
how flexible querying of geo-tagged documents with missing and impre-
cise data, referring to a geographical hierarchy, can benefit from data
veracity handling. The technique is illustrated by a practical implemen-
tation as a script executed by the J-CO Framework that queries the
Database of historic Byzantine Book Epigrams (DBBE). An experimen-
tal evaluation demonstrates the potential of the approach.
